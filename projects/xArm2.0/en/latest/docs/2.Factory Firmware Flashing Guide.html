2. Factory Firmware Flashing Guide ​

2.1 Factory Firmware Flashing Guide ​

2.1.1 Overview ​

The CoreX controller of the xArm 2.0 features an ESP32 as its main control chip. This chip supports two development modes: Arduino and MicroPython (used by both Python and Scratch programming).

Some key libraries, such as those for low-level communication and motion control, are used in the routines. For MicroPython development, these libraries are precompiled into firmware and pre-flashed to the ESP32 (by default at the factory) to be available for program calls.

However, uploading an Arduino-based program will overwrite the factory firmware. Therefore, if you wish to switch back to using Scratch or Python after uploading an Arduino program, you must re-flash the factory firmware.

2.1.2 Firmware Flashing ​

  1. Open the file firmware flashing tool\flash_download_tool_3.9.7\flash_download_tool_3.9.7.exe
  1. In the pop-up window, set Chip Type to ESP32, leave the other settings as default, and click OK.
  1. Once the tool opens, click the "..." button to select the .bin firmware file you want to flash.
  1. Make sure the checkbox on the left is selected. Configure the remaining settings according to the reference image provided. For the COM port, select the port assigned to the CoreX board in your system.
  1. Click "ERASE" to erase the previously flashed firmware (this step is required). Wait for the process to complete — the status on the left should change to “FINISH”.
  1. Click "START" to begin flashing the selected firmware. Wait for the download to complete — once finished, the firmware has been successfully re-flashed.
