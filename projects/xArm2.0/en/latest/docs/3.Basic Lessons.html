3.1 Dot Matrix Display ​

Download Scratch program

3.1.1 Preparation ​

  1. Prepare the power adapter for the xArm2.0.

  2. Prepare an xArm2.0 robotic arm that has been commissioned and place it in any position without placing it on the map.

3.1.2 Programming ​

  1. Connect the power adapter of the xArm2.0 and turn on the switch;

  2. According to the method in “Start the Gameplay”.Download the provided game program of “Dot Matrix Display” to the main controller.

Dot Matrix Display Program

After the program download is completed, the LED dot matrix module on the xArm2.0 robot arm will alternately display "Hi", "I", "AM", "xArm2.0", the self-introducing English word.

3.5 Color Identify ​

Download Scratch program

3.5.1 Preparation ​

  1. Prepare 3 different color blocks.

  2. Prepare the power adapter for the xArm2.0.

  3. Prepare an xArm2.0 robotic arm that has been commissioned and place it in any position without placing it on the map.

3.5.2 Programming ​

  1. Connect the power adapter of the xArm2.0 and turn on the switch;

  2. According to the method in “Start the Gameplay”.Download the games program of “Color Sorting” to the main controller.

  1. Color Sorting

3.5.3 Project Outcome ​

Place color patches of different colors above the color sensor. When the color sensor recognizes the color of the block, the capital letter of the English word that recognizes the block is displayed on the LED dot matrix screen. At this time, the main controller lights up the corresponding color and executes the corresponding clamping action group. Here is an example of recognizing the blue color block: when the blue color block is recognized, the letter “B” is displayed on the LED dot matrix screen, the blue light of the main controller lights up, and the action of clamping the block No. 1 is executed.

3.8 Multi-directional Detection ​

Download Scratch program

3.8.1 Preparation ​

  1. Prepare 3 different color blocks.

  2. Prepare the power adapter for the xArm2.0.

  3. Prepare an xArm2.0 robotic arm that has been commissioned and place it in any position without placing it on the map.

3.8.2 Programming ​

  1. Connect the power adapter of the xArm2.0 and turn on the switch;

  2. According to the method in “Start the Gameplay”.Download the games program of “Multi-directional Detection” to the main controller.

  1. Multi-directional Detection
  1. Place the 3 color blocks on the "1", "4" and "5" areas of the attached map.

3.8.3 Project Outcome ​

Multi-directional detection can detect objects in multiple directions in front of the ultrasonic sensor. After downloading the program to the xArm2.0 robotic arm, place 3 color blocks in the "1" "4" "5" area on the map in front of the ultrasonic sensor. After the ultrasonic sensor detects an item in a certain direction, the LED dot matrix screen will displays the detected direction "arrow", and then it will perform the grabbing action in this direction.
